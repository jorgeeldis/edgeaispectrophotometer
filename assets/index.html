Operating Guide

A — Quick Measurement (Category "Other")

Characterise any liquid. No reference or model needed — works from day one.

1 — Settings: sample name, category Other, reference No, known value blank

2 — Insert distilled water → Baseline

3 — Insert sample → Single Scan

4 — Review spectrum and key values on Home

5 — Save Data, then confirm in Measures

6 — Reports: PDF with spectrum, key values and baseline used

No score or prediction — "Other" has no reference profile.

B — Build a Reference Profile

Defines what a good sample looks like. Enables anomaly detection.

1 — Settings: name Milk_ref_01, category, reference Yes, known value 0

2 — Insert distilled water → Baseline

3 — Insert reference sample → Single Scan → Save Data

4 — Remove and reinsert the cuvette (same marked face), rename to _02, scan and save again

5 — Repeat to 5–10 replicates

6 — Analysis → select category → Build Reference

Reinserting between replicates is essential — without it σ measures only electronic noise, not real measurement variation.

The reference is the 0 % point of the dilution series, so known value is always 0.

C — Dilution Series & Training

Teaches the model to predict numeric values. Requires Flow B first.

1 — Prepare 5 dilutions by mass (0.1 g scale):

   Milk — 10/20/30/40/50 % added water

   Coffee — 2/4/6/8/10 g/L instant coffee

   Water — 4/8/12/16/20 % of dye stock

2 — Settings per sample: category, reference No, known value = that dilution

3 — Insert distilled water → Baseline

4 — Measure 3 replicates per level in random order (Milk_30_a, _b, _c)

5 — Re-run Baseline every 8–10 samples

6 — Analysis → Sanity Plot: expect a straight line, R² > 0.99

7 — Analysis → Train Model → review metrics → Accept

Never measure 10→20→30→50 in order: thermal drift would correlate with concentration and the model would learn the warm-up curve instead of the chemistry.

Start with the dye series — exactly known concentrations and pure Beer-Lambert absorbance, so it should come out linear. If it doesn't, the fault is optical, not chemical.

D — Unknown Sample

Normal operation once calibrated.

1 — Settings: name, category, reference No, known value blank

2 — Insert distilled water → Baseline

3 — Insert sample → Single Scan → Save Data

4 — Analysis shows deviation σ, PASS / ATTENTION / REJECT, and — if a model exists — predicted value with confidence

5 — Select several rows for batch-level metrics

6 — Reports: full PDF with prediction, deviation and baseline used

What Each Flow Unlocks

Flow A alone spectrum + key values

After Flow B deviation σ + status

After Flow C numeric prediction + confidence

Other Tabs

Measures — raw history of every saved scan. Select a row for detail and export.

Maintenance — calibration age, baseline drift, sensor health, internal temperature. Re-run Baseline when flagged.

Reports — saved PDFs for single scans and full analyses.

Chat — on-device AI assistant with access to your measurement data. Runs locally, so no measurement leaves the instrument.
